# 二进制插件包

`az-plugin-package` 是 CLI 和插件中心共用的 `.aio-plugin` 契约。格式 2 是确定性 gzip 压缩的 UTF-8 JSON，包含发布来源、SemVer 版本、可选源码提交、清单、后端产物和可选前端资产集合。一个功能的页面、服务和子插件统一随一个包发布；格式 1 直接迁移，不提供兼容解码。

`PluginPackage::new` 的最后一个参数为前端相对路径到字节的 `BTreeMap`，无前端时传空集合。`encode` 输出传输字节，`decode` 有界解压并验证，`verify` 返回已校验的清单、后端字节和前端字节集合。后端产物上限 32 MiB，前后端合计 64 MiB，前端最多 256 个文件，清单 128 KiB，压缩包 48 MiB，解压 JSON 96 MiB；base64 在解码前检查长度。压缩时间戳固定为零，不携带本地文件名。

`rev` 是域分隔的 SHA-256 内容摘要，覆盖格式、规范化 Git 来源、版本、可选源码提交、完整清单、后端 SHA-256 和排序后的每个前端路径及 SHA-256。任一端修改都会改变整个包版本。路径校验拒绝目录穿越、符号链接、大小写冲突、跨平台设备名以及前端覆盖清单或后端的冲突。Git 来源只用于发布者归属与审计，不证明源码和构建产物一致，也不要求有本地 Git 仓库。旧 GitProof JSON 请求不属于此协议。

HTTP 发布使用 `Content-Type: application/vnd.aio.plugin+gzip`，正文直接发送 `.aio-plugin` 字节，不设置 `Content-Encoding`。包的完整性校验不替代宿主的来源鉴权、能力授权、运行实例健康检查与激活事务。
